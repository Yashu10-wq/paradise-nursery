# Paradise Nursery

Paradise Nursery is a React-based online plant shopping application.

The application allows users to:

- Browse different categories of houseplants
- View plant names, prices, and thumbnails
- Add plants to a shopping cart
- Increase or decrease plant quantities
- Remove plants from the cart
- View the total cost of their shopping cart
- Continue shopping from the cart page

## Technologies Used

- React
- Vite
- React Router
- Redux Toolkit
- React Redux
- CSS

## Plant Categories

The application contains three plant categories:

1. Indoor Plants
2. Flowering Plants
3. Aromatic Plants

## Project

The Paradise Nursery project demonstrates a dynamic e-commerce shopping cart application using React and Redux.
